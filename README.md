# Voedingstracker

Web-app om calorieën en eiwit per dag bij te houden. Werkt offline en kan op het beginscherm van een telefoon gezet worden.

- Alle gegevens blijven op het toestel (opslag van de browser). Er wordt niets doorgestuurd.
- Voedingswaarden zijn gemiddelden per 100 g of ml en blijven een schatting.
- Bij een nieuwe versie: verhoog het versienummer van `CACHE` in `sw.js`.
